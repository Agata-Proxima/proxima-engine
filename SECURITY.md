# Security Policy

## Reporting a vulnerability

Please do not publish exploitable vulnerabilities, credentials, tenant data, or sensitive logs in public issues or pull requests.

Until a dedicated private security-reporting channel is published, use the contact options on the [Agata Proxima GitHub organization](https://github.com/Agata-Proxima) to request a private disclosure route. Please include:

- The affected commit or release
- A concise impact assessment
- Reproduction steps or a proof of concept that does not expose real data
- Any known mitigations

Do not send production secrets or customer data.

## Response expectations

The maintainers will review reports as capacity allows. No guaranteed response or remediation timeline is currently published. Please allow maintainers reasonable time to investigate before public disclosure.

## Supported versions

No formal release-support matrix has been published yet. When reporting an issue, include the exact commit SHA and Rust toolchain used.
